# Titanic Passenger Data Preprocessing

**Codveda Technologies | Machine Learning Internship | Level 1 — Task 1**

## Overview

This project implements a reproducible data preprocessing workflow using the Titanic passenger dataset. The goal is to transform raw passenger records into clean, numerical, and model-ready features while ensuring consistency and preventing data leakage.

The workflow is built using Python, pandas, and scikit-learn, with a focus on reliable data preparation rather than predictive modeling.

## Project Objectives

- Explore the dataset and identify data quality issues.
- Handle missing values in numerical and categorical features.
- Encode categorical variables using One-Hot Encoding.
- Standardize numerical features.
- Perform a stratified training and validation split.
- Build a reusable preprocessing pipeline.
- Validate and export the processed datasets.

## Dataset

**Source:** [Titanic — Machine Learning from Disaster](https://www.kaggle.com/competitions/titanic/data)

The dataset contains 891 labeled passenger records and 12 original columns, including passenger demographics, ticket information, and survival outcomes.
